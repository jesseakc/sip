# ATO-003: MCP metadata and tool contract standards

Status: proposal, pending implementation and independent review.
Priority: P1

## Problem and scope
Define naming, concise task-based descriptions, JSON schemas, examples, error taxonomy, idempotency, pagination, permissions, destructive-action approvals and semantic versioning. Provide linter/test and exemplar asset-history and work-order tools. Acceptance: schema validation, tests for ambiguity, auth and error handling; no production capability misrepresentation.

## Delivery constraints
- Preserve human approval for merges to main.
- No secrets, real customer data, or production mutations in tests.
- Follow existing SIP conventions; audit before implementation.
- Integrate with observability and deployment milestones without blocking critical infrastructure work.
- PR Worker may implement in bounded, independently verified slices; Repogan review is required before human merge approval.
