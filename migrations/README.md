# Database Migrations

This directory contains SQLx database migrations for the SIP platform.

## Running Migrations

```bash
# Install sqlx-cli (if not already installed)
cargo install sqlx-cli --no-default-features --features native-tls,postgres

# Run migrations
sqlx migrate run

# Create a new migration
sqlx migrate add <migration_name>
```

## Migration Naming

Migrations are prefixed with a timestamp and should be named descriptively:
- `0001_create_organization_table.sql`
- `0002_create_user_and_rbac.sql`

## Policies

- Migrations must be immutable after merge. If a change is needed, create a new migration.
- All tables use `timestamptz` for timestamps.
- All primary keys are `UUID` generated by `gen_random_uuid()`.
- Soft deletes use `archived_at` where specified.
- Indexes should be added in the same migration that creates the table, or in a follow-up migration with performance justification.
