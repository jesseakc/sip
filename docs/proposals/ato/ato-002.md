# ATO-002: Golden agent-intent benchmark and evaluation fixtures

Status: proposal, pending implementation and independent review.
Priority: P1

## Problem and scope
Create 25-30 realistic scenarios across core, infrastructure, contracts, inventory, diagnostics, and expenses, including negative and cross-tenant tests. Define expected tool/no-tool, schema, permissions, outcomes, precision/recall, latency and reproducible CI harness. Synthetic data only. Acceptance: deterministic local tests and documented metrics; external discovery separately labeled non-deterministic.
